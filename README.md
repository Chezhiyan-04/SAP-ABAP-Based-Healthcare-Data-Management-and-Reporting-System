## 📌 Project Overview

This project is developed using SAP ABAP to improve healthcare data management.  
The system helps hospitals and clinics manage patient records, generate reports, and maintain secure healthcare information efficiently.

---

## 🚀 Features

- Patient Record Management
- Automated Report Generation
- Secure Data Storage
- SAP Database Integration
- Efficient Workflow Management
- User-Friendly Interface

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| SAP ABAP | Backend Development |
| SAP GUI | User Interface |
| ALV Reports | Reporting |
| Internal Tables | Data Processing |
| Smart Forms | Report Generation |

## ⚙️ How to Run

1. Open SAP GUI
2. Login into SAP System
3. Open Transaction Code `SE38`
4. Execute the ABAP Program
5. Run the modules
